# MuffMode Changelog

[README](../README.md) | [Release Process](release-process.md)

This is the central change ledger for MuffMode. Every implementation should leave one grouped, user-readable row here before it is considered complete. Review the existing `Unreleased` rows first: if the new work belongs with an existing change, edit that row's summary, details, category, or magnitude instead of adding a near-duplicate row.

`Release` stays `Unreleased` until the release script stamps it with the shipped version. `Magnitude` is release-note impact: `major` changes are eligible for release highlights, `minor` changes are notable but not headline material when major changes exist, and `patch` changes are narrow fixes or maintenance.

| Unreleased | Internal Maintenance | patch | The UndefinedBehaviorSanitizer build links again | Making sanitizer build failures blocking revealed that this one had never linked: clang ships its sanitizer runtimes built against the release CRT, so a debug build pairs `libcpmtd.lib` at `_ITERATOR_DEBUG_LEVEL` 2 with `clang_rt.ubsan_standalone_cxx` at 0 and `lld-link` refuses it. The gate now builds this sanitizer against the release CRT, which is the configuration clang supports on Windows, while an explicit configuration from the caller is still honoured. AddressSanitizer is untouched, since it uses the MSVC runtime and links against the debug CRT correctly. |
| Unreleased | Internal Maintenance | patch | Dependency restore no longer depends on a rotating MSYS2 download | Both manifest ports finish with vcpkg's `vcpkg_fixup_pkgconfig()`, which resolved pkg-config from one hardcoded MSYS2 `pkgconf` build. MSYS2 serves only current package versions, so when that build was rotated out the download began failing on every mirror and each job died in `Setup vcpkg` before compiling anything -- surviving only where an old `actions/cache` entry still held the archive. The restore now builds pkg-config from the same pinned baseline, whose own `pkgconf` port fixes its files up with `SKIP_CHECK` and so needs no pkg-config to exist first, and points vcpkg at it through `PKG_CONFIG`; a `PKG_CONFIG` already set in the environment is honoured, and a copy surviving in the cached package staging is reused rather than rebuilt. A first-run clone can also complete now: the guard that refuses to replace a modified vcpkg checkout no longer fires on the empty `--no-checkout` clone the script just made itself, which had made a machine with no vcpkg present unable to bootstrap at all. |
| Unreleased | Player Experience | minor | Ranked matches end with a post-match awards reel | The end of a ranked match now reads as three screens in a row -- the scoreboard, then the awards reel, then the next-map pick -- each handing on to the next the same way: a minimum hold so nobody presses straight through it, then any key, with a timeout so an unattended server still moves. The reel replaces the scoreboard with up to twelve awards: a title in green with the player who earned it in white underneath, centred, one blank line between each pair. It stays up for `g_match_awards` seconds unattended (default `10`, `0` disables, clamped to `3`-`30`) and takes a key press after the first three seconds, which stops the press that dismissed the scoreboard from carrying straight through it unseen. It follows the next-map pick's contract, being offered the exit by every intermission path that was about to change level and offering that same exit on to the pick when it is done, which also fixes that path for humans-only servers where `ready_to_exit` is only ever set for bots. Every award needs a strict winner, so a tie awards nobody, and every award has a floor to clear. The catalog spans earned titles (`SHOTGUN SHERIFF` and `RAIL SLUT` for a dominant, high-volume, high-share signature weapon, `ROCKET SURGEON`, `LEAD FARMER`, `PINEAPPLE EXPRESS`, `BIG FRAGGING GUN`, `AIMBOT ALLEGATIONS` for 80%+ accuracy over a real sample, `UNTOUCHABLE`, `WRECKING BALL`, `TOP DOG`, `FIRST BLOOD`, `THE HUMILIATOR`, `ON A RAMPAGE`), observed habits (`SPAWN FRAGGER`, `DIRTY ROTTEN CAMPER`, `KLEPTOMANIAC`, `THE COCKROACH`), CTF specialisms (`FLAG RUNNER`, `LAST LINE OF DEFENCE`, `RETURN TO SENDER`, `PACK MULE`), and the deserved (`QUAD DUMMY` for hoarding the Quad and doing nothing with it, `THE PUNCHING BAG` for being non-lethal on both K/D and damage traded, `STORMTROOPER`, `BULLET SPONGE`, `MAYFLY`, `LEMMING`, `BUTTERFINGERS`, `BENEDICT ARNOLD`). Awards are ordered honours first so an oversubscribed reel drops the jokes rather than the wins, and one player takes at most three titles before the rest are offered around, with unused slots back-filled afterwards. Two new counters feed the catalog, both collected only while a match is recorded: kills landed while the attacker's Quad was still running, which is what separates `QUAD GOD` from `QUAD DUMMY` alongside the share of Quad spawns that player took off the floor, and a once-a-second position sample of every living player bucketed into 512-unit cells, from which the camping share is derived; samples taken while the inactivity timer had a player flagged are counted separately and disqualify them, so an idle body cannot out-camp somebody who was actually playing. Awards are offered only in genuinely ranked matches: `g_ranked` on, not Rocket Arena, no bot participants, at least two humans, at least a minute of play, and somebody still connected to read the reel. Fixes three long-standing intermission faults found while wiring the new stage in: `level.exit_time` and `ready_to_exit` were never cleared when an intermission began, so a second intermission inside one level load skipped the scoreboard's five-second minimum entirely and exited on its first frame; an admin `nextmap` or a passed `nextmap` vote was swallowed by whichever post-scoreboard stage held the intermission, announcing a map change that did not happen and letting the pick choose a different map than the one announced; and both stages now retire cleanly when either of those authorities forces the change. What a player earned is repeated in their end-of-match summary, reprintable with the new `awards` command, exported in the match JSON and HTML both match-wide and per player, and accumulated into their career profile under `stats.awards`. |
| Unreleased | Competitive Play | minor | Arena rooms warm up like MuffMode, and bots pick a room and an opponent | Each Arena room now runs its own MuffMode warmup instead of starting the instant two sides happen to pair up. A room tracks what it is waiting on and says so: a centerprint every 30 seconds while it needs players or the teams are uneven, a per-player "You are NOT ready (n/m ready)" nudge on the same cadence once ready-up is the only thing left, `WARMUP - NEED PLAYERS` / `WARMUP - UNBALANCED` / `WARMUP (n/m READY)` on the HUD, and the same reason on the scoreboard. Ready-up is now available in an ordinary room through the new `g_arena_warmup_readyup` (default `1`), not just competition mode, and `ready` explains what is still missing rather than refusing silently; setting it to `0` restores the previous start-on-pairing behavior. The countdown became a real one, with a tick on every ten and every second under ten, spoken numbers for the last three, a prepare-to-fight sting at the top, and a header that no longer fades before FIGHT. Because every room keeps its own copy of this state, several rooms can wait, balance, and count down at once without touching the level-wide match state. Room warmup reuses the shared warmup cvars (`minplayers`, `g_warmup_ready_percentage`, `g_dm_allow_no_humans`), and the first countdown of a series now uses `g_warmup_countdown` while later rounds keep `g_round_countdown`. Bots understand rooms: instead of scattering into the emptiest room each and waiting forever, a bot follows players into an occupied room, prefers one where somebody has nobody to fight, and joins an opposing team, founding one when a lone player is waiting; it re-evaluates once a second while it is not a fighter and never churns a settled roster. Bots also no longer have the join menu opened on them, which had left every Arena bot with a menu it could never close and its weapon logic suppressed for the rest of the map. The room scoreboard was rebuilt in MuffMode's visual language: the shared footer block, an 8px row ladder with SC/ping column headers, real team names and scores instead of hard-coded RED/BLUE, captain, ready, and alive markers, the killer tag, warmup rosters so the board is not empty exactly when players want to see who is lined up, a waiting/observing block that only appears when somebody is waiting, and a byte budget that stops mid-board rather than dropping a chunk and rendering the rest out of order. Arena centerprints now carry the MuffMode marker, so room chatter stays out of the console like every other match message. |
| Unreleased | Player Experience | minor | Players choose the next map after the end-of-match scoreboard | Ports WORR's MapSelector as a server-side next-map pick. Once the scoreboard is done the intermission camera holds instead of changing level, and everyone picks the next map from up to three candidates over `g_map_pick` seconds (default `15`, `0` disables, clamped to `5`-`60`). Candidates come from the same eligibility rules the automatic rotation already uses, so the pick can only offer a map the rotation would have loaded anyway, and never the current one. Choose with the movement keys and attack/jump or with `mappick <1-3>`; live tallies sit beside each map, your own choice is highlighted, and a vote can be changed until the timer ends. A map holding more than half the eligible voters wins immediately, ties break at random, and a pick nobody voted in still lands on one of the offered maps rather than falling back. Eligibility follows `g_allow_spec_vote`; bots never vote and never count toward the majority. WORR drives its selector from a client-side RmlUi page, so the menu is rebuilt on MuffMode's layout menu and taught to survive intermission, where selection, usercmd routing, and menu refreshes are all normally switched off. The pick stands down and the level changes as before in Rocket Arena, on end-of-unit exits, when a `mymap` entry, `g_dm_same_level` or a forced map already settled the next map, when fewer than two candidates exist, or when no human players remain. The inventory bind cannot take the pick away from anyone: `inven` does nothing while the pick or the awards reel is up, where it used to close the pick menu -- and once the winner was on screen, close it for good -- or drop a join menu over the reel that could not be used from intermission anyway. The pick also restores a menu lost during the winner reveal, not just while it is still taking votes. |

# MuffMode Changelog

[README](../README.md) | [Release Process](release-process.md)

This is the central change ledger for MuffMode. Every implementation should leave one grouped, user-readable row here before it is considered complete. Review the existing `Unreleased` rows first: if the new work belongs with an existing change, edit that row's summary, details, category, or magnitude instead of adding a near-duplicate row.

`Release` stays `Unreleased` until the release script stamps it with the shipped version. `Magnitude` is release-note impact: `major` changes are eligible for release highlights, `minor` changes are notable but not headline material when major changes exist, and `patch` changes are narrow fixes or maintenance.

| Release | Category | Magnitude | Summary | Details |
| --- | --- | --- | --- | --- |
| Unreleased | Gameplay and Balance | major | Q3A and Quake rulesets brought closer to their source-game feel | Expands the ruleset weapon, ammo, armor, spawn-remap, projectile, splash, knockback, and loadout behavior for Quake III Arena style and Quake style play, including Q3-style weapon mappings, shotgun and BFG tuning, Quake armor handling, and clearer player-facing ruleset documentation. |
| Unreleased | Gameplay and Balance | major | Capture Strike uses Threewave-style team scoring | Moves Capture Strike scoring into a dedicated `mm_strike` module: offense earns 1 point for first enemy-flag touch and 2 more for a capture or defender wipe, defense earns no team points, match length uses `capturelimit`, and shipped Strike defaults are 100/100 arena spawns with `capturelimit 15`. |
| Unreleased | Gameplay and Balance | major | Red Rover gains round resets, round winners, and cleaner match flow | Adds Quake Live style Red Rover round resets with per-round reshuffles, roundlimit/timelimit handling without fraglimit ending the match early, damage and score snapshots for round-winner announcements, warmup recovery when one side is empty, and fixes for round damage and map-transition warmup stalls. |
| Unreleased | Gameplay and Balance | major | Horde waves gain adaptive AI, pacing, and clearer item timing | Adds enhanced Horde AI for target spread, tactical spawn selection, retargeting, aggro, stagger, adaptive budget and spawn pressure, plus `g_horde_item_respawn_scale` for non-weapon item respawn timing while keeping weapon respawn cvars truthful. Raises the player-scale cap for larger groups. |
| Unreleased | Fixes | major | Weapon think null guard prevents no-weapon crashes | Prevents a crash in `Weapon_RunThink` when accelerated weapon ticking lets a think callback switch or clear the current weapon before the next loop iteration reads `pers.weapon`. |
| Unreleased | Fixes | minor | Team chat, death scoreboard, and melee impact paths are hardened | Maps internal MuffMode teams back to engine `team_index` values for lobby `say_team` filtering, gates automatic death scoreboards behind `g_dm_death_scoreboard`, and guards melee impact handling when `self->enemy` is already null. |
| Unreleased | Player Experience | minor | Map and gametype commands show clearer server choices | Lets all players list gametypes while keeping gametype changes admin-only, shows gametype short names instead of numeric indexes, prints both rotation maps and votable map pools in `maplist`, and allows safe subdirectory map names such as `q64/outpost`. |
| Unreleased | Player Experience | minor | Teammate location callouts gain macros and fallbacks | Adds the `loc` command for private teammate callouts with `%l` location, `%h` health, `%a` armor, `%w` weapon/ammo, `%m` current ammo, `%n` nearby teammates, and `%N` nearby players. Map `.loc` files are parsed safely, and maps without loc files fall back to visible landmark items or the map/water name. |
| Unreleased | Player Experience | minor | Skin overrides are per-player and safer by default | Adds `eskin` and `tskin` per-viewer enemy/team skin overrides behind `g_allow_skin_overrides`, refreshes overrides when following players, rejects extra skin command arguments, and defaults `g_team_force_models` off so team skins are not forced unless enabled. |
| Unreleased | Server Hosting | minor | Server nav baking can generate bot navigation files | Adds the server-side `nav_bake` command, project files, and nav-file format documentation for generating bot navigation data from maps. |

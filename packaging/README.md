# Release Packaging Assets

The release script copies everything under `packaging/release-assets` into the root of the generated package before adding the built DLL, Copilot-generated end-user readme, Copilot-generated changelog, `LICENSE`, `THIRD_PARTY_NOTICES.md`, updater/launcher executable, and installer-ready version markers.

Use this directory as a mirror of the package layout. For example:

```text
packaging/release-assets/
  rerelease/
    baseq2/
      muff-sv.cfg
      SERVER_CONFIGS.md
      bots/
        navigation/
          example.nav
      maps/
        example.ent
```

The `muffmode-0.22.15-beta.zip` package used this shape:

```text
muffmode-0.22.15-beta/
  README.md
  MuffModeUpdater.exe
  rerelease/
    baseq2/
      game_x64.dll
      muffmode-version.json
      muffmode.version
      muff-sv.cfg
      SERVER_CONFIGS.md
      bots/navigation/*.nav
      maps/*.ent
      maps/*.bsp
```

New packages generated by `scripts/release.ps1` use the same top-level folder shape, but include an end-user `README.html`, audience-focused `CHANGELOG.md`, `MuffModeUpdater.exe`, and updater-readable version markers in `rerelease/baseq2`.

Every generated package must include `LICENSE` and `THIRD_PARTY_NOTICES.md` at the package root.

The same staged package root is also compiled into `muffmode-<version>-<channel>-windows-installer.exe` through [packaging/installer/muffmode-installer.iss](installer/muffmode-installer.iss). The installer presents detected Steam, Epic Online Store, and GOG paths, keeps an other-location choice available, and offers Desktop/Start menu shortcuts for the updater and launcher.

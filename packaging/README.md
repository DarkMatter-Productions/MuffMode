# Release Packaging Assets

The release script copies everything under `packaging/release-assets` into the root of the generated package before adding the built DLL, generated end-user HTML guides, generated changelog, `LICENSE`, `THIRD_PARTY_NOTICES.md`, updater/launcher executable, and installer-ready version markers.

Use this directory as a mirror of the package layout. For example:

```text
packaging/release-assets/
  rerelease/
    baseq2/
      server-base.cfg
      CONFIGS_README.md
      factories.cfg
      mapdb.json
      muffmode-map-pool.json
      muffmode-map-cycle.txt
      lobby-casual.cfg
      lobby-competitive.cfg
      lobby-party.cfg
      lobby-horde.cfg
      gt-*.cfg                 # inert v0.60.20 updater bridge markers in ZIP only
      maps/
        example.ent
        example.bsp
    bots/
      navigation/
        example.nav
```

A generated package uses this shape:

```text
muffmode-<version>-<channel>/
  README.md
  MuffModeUpdater.exe
  rerelease/
    baseq2/
      game_x64.dll
      muffmode-version.json
      muffmode.version
      server-base.cfg
      CONFIGS_README.md
      factories.cfg
      mapdb.json
      muffmode-map-pool.json
      muffmode-map-cycle.txt
      lobby-casual.cfg
      lobby-competitive.cfg
      lobby-party.cfg
      lobby-horde.cfg
      maps/*.ent
      maps/*.bsp
    bots/navigation/*.nav
```

New packages generated by `scripts/release.ps1` use the same top-level folder shape, but include an end-user `README.html`, audience-focused `CHANGELOG.md`, `MuffModeUpdater.exe`, and updater-readable version markers in `rerelease/baseq2`.

The update ZIP temporarily generates ten non-empty, inert `gt-*.cfg` marker
files required by MuffModeUpdater v0.60.20's pre-install validation. Current
updaters skip these retired names, and the Windows installer excludes them, so
they cannot recreate or overwrite legacy operator configs on modern paths.
The v0.60.20 updater itself predates config backups and in-place self-update;
its users should preserve customized legacy files and bootstrap the current
updater through the installer or a manual replacement while it is closed.

When localized guides are generated, the English `README.html` includes a language switcher and the installer ships translated siblings: `README.de.html`, `README.pl.html`, `README.fr.html`, `README.hu.html`, and `README.bg.html`. English-only local packages keep a self-contained English language switcher.

Every generated package must include `LICENSE` and `THIRD_PARTY_NOTICES.md` at the package root.

The same staged package root is also compiled into `muffmode-<version>-<channel>-windows-installer.exe` through [packaging/installer/muffmode-installer.iss](installer/muffmode-installer.iss). The installer fails compilation if the staged package is missing required user-facing files, any expected translated guides, updater files, version markers, original-map readme bundle, custom map BSPs, selected entity overrides, the production KEX map database, structured map pool and cycle, all four lobby presets, the rest of the server config bundle, `rerelease/baseq2/game_x64.dll`, or the launcher icon. The compiler also embeds SHA-256 hashes for the packaged DLL, updater, docs, included translated guides, legal notices, version manifest, original-map readmes, custom map BSPs, selected entity overrides, server and lobby configs, `mapdb.json`, and the structured map-pool/cycle files so the installed payload can be verified after copy.

The Windows installer presents detected Steam, Epic Games Store, GOG, and Xbox app / Microsoft Store paths, keeps an other-location choice available, shows the resolved target on the Ready page, and offers Desktop/Start menu shortcuts for the updater/launcher, install guide, changelog, and server config guide. During install it corrects accidental `rerelease` or `baseq2` folder selections, requires a real Quake II root with `rerelease/baseq2` and a known launcher executable, rejects extracted Muff Mode package roots plus unsafe system/special-folder/temp/backup-folder targets and reparse-point payload/backup paths, registers the existing DLL/updater for close-applications handling, checks that the target `baseq2` folder is writable, warns if Quake II appears to be running, bounds automatic backup count and size with reserved disk space, skips duplicate backups when the existing DLL already matches the package, backs up previous Muff Mode version markers and server/map-policy files when present, verifies installed docs/legal/original-readme/custom-map/entity/config/version-manifest contents, verifies the exact packaged map and lobby assets, and writes `rerelease/baseq2/muffmode-install-receipt.txt` after a verified install.
